Voice-over machine

Upload authorized voice samples, enter the line, and generate a cloned voice-over from the Vercel app. Heavy local XTTS/RVC engines remain in the repo for Docker/local use; this hosted version uses cloud voice infrastructure that fits Vercel serverless.

Accuracy rule: clean, single-speaker WAV/FLAC samples produce the best clones. Instant cloud cloning is fast; professional fine-tuned voice models are still the path for the closest production match.

Instant mode returns audio immediately. Worker mode queues the job for a local/GPU/container worker running Qwen, XTTS, RVC, Demucs, and DSP.

Replacement/conversion and RVC training jobs use the queued worker so the app can run local/GPU processing.

Use clean single-speaker WAV/FLAC. Studio-match mode requires at least 20 seconds; 60+ seconds is better.

Upload samples to check clone readiness.

For songs, upload audio with a vocal to replace. For beats/instrumentals with no vocal, use text voice-over and the optional browser mix bed below.

Use center-channel for quick checks. Use Demucs for better real song separation after the model is cached on the worker.

# dataset/

Place ONLY your own recorded or licensed audio here. Never commit copyrighted acapellas.

This directory is for **authorized** voice source material:

- Audio you recorded yourself (your own voice, or a subject who signed
  `CONSENT.md`-style permission paperwork).
- Properly licensed audio you have explicit written rights to use for
  voice cloning / model training.

Anything else — celebrity acapellas, ripped stems, leaked vocals, YouTube
extracts — stays OFF this repo, even with a `--i-have-permission` flag.
The flag is a legal attestation, not a license.

Everything under `dataset/` is git-ignored. If you genuinely need to share
a *config* (e.g. `Pacaveli/config.json`-style metadata), commit it under a
different top-level directory instead.
